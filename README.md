# ALOSTOURA Typing SVG

**استوديو الأسطورة لإنشاء النصوص المتحركة بصيغة SVG**

إنشاء لافتات نصية متحركة واحترافية لملفات GitHub والملفات الشخصية وملفات التوثيق مع معاينة فورية وتحكم كامل في التصميم والحركة.

## ✨ مميزات المشروع

- 🌍 واجهة استخدام عربية وإنجليزية مع دعم اتجاه الكتابة من اليمين إلى اليسار
- 📝 إمكانية إضافة حتى 10 عبارات نصية متتابعة
- 🎬 14 تأثيرا حركيا للنصوص
- 🎨 12 قالبا بصريا جاهزا وقابلا للتخصيص
- 💾 حفظ تلقائي للإعدادات واستعادتها محليا
- 👁️ معاينة فورية للنتيجة أثناء التعديل
- 🔤 التحكم في نوع الخط وحجمه وسمكه ومحاذاته
- 🌈 تخصيص ألوان النصوص والخلفيات
- 🪟 دعم الخلفيات الشفافة
- 📐 التحكم في العرض والارتفاع وأبعاد التصميم
- ⏱️ التحكم في سرعة الكتابة ومدة التوقف بين العبارات
- 📦 تصدير الملفات بصيغ SVG وMarkdown وHTML
- ⚡ يعمل مباشرة داخل المتصفح دون الحاجة إلى خادم خلفي
- 🔑 لا يحتاج إلى حساب مستخدم أو مفتاح API
- 📱 متوافق مع الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر
- 🧩 لا يعتمد على مكتبات JavaScript خارجية

## 🎬 التأثيرات الحركية

يوفر المشروع مجموعة متنوعة من التأثيرات لإضفاء الحيوية على النصوص:

| التأثير | الوصف |
|---|---|
| Typewriter | الكتابة حرفا بعد حرف |
| Fade | الظهور والاختفاء التدريجي |
| Slide | الدخول من اتجاهات مختلفة |
| Bounce | الارتداد |
| Zoom | التكبير والتصغير |
| Rotate | الدوران |
| Blur | التمويه |
| Glow | التوهج |
| Flip | القلب |
| Elastic | الحركة المرنة |
| Pulse | النبض |

## 🚀 البدء في الاستخدام

1. قم بتنزيل المشروع أو استنساخ المستودع.
2. افتح ملف `index.html` باستخدام متصفح حديث.
3. أدخل العبارات النصية التي تريد عرضها.
4. اختر التأثير الحركي والقالب المناسب.
5. خصص الألوان والخطوط والأبعاد والتوقيت.
6. شاهد النتيجة مباشرة في نافذة المعاينة.
7. حمّل ملف SVG النهائي.
8. ارفع الملف إلى مستودع GitHub الخاص بك.

### إضافة التصميم إلى ملف README

بعد تنزيل ملف SVG يمكنك إضافته إلى مستودعك واستخدام الكود التالي:

```html
<p align="center">
  <img
    src="assets/ALOSTOURA-Typing.svg"
    alt="لافتة نصية متحركة"
  >
</p>
```

## 🌐 تفعيل الاستضافة على GitHub Pages

لتشغيل المشروع من خلال رابط عام اتبع الخطوات التالية:

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. افتح إعدادات المستودع.
3. انتقل إلى قسم Pages.
4. اختر النشر من أحد فروع المستودع.
5. حدد الفرع الرئيسي `main`.
6. اختر مجلد الجذر `/ (root)`.
7. اضغط على حفظ وانتظر اكتمال النشر.
8. افتح رابط المشروع بعد تفعيله.

لا يحتاج المشروع إلى أوامر بناء أو تثبيت حزم إضافية.

## ⚙️ آلية عمل المشروع

يعتمد المشروع على تقنيات الويب القياسية لإنشاء الرسومات المتحركة:

- HTML لبناء واجهة الاستخدام.
- CSS لتنسيق التصميم والتأثيرات البصرية.
- JavaScript لإدارة التفاعلات والإعدادات.
- SVG لإنشاء الرسومات والنصوص المتحركة.
- SVG SMIL لتشغيل التأثيرات الحركية.
- التخزين المحلي للاحتفاظ بإعدادات المستخدم.

## 🔐 الخصوصية والأمان

- لا يتم إرسال النصوص التي يدخلها المستخدم إلى أي خادم.
- تتم معالجة البيانات محليا داخل المتصفح.
- لا يتطلب المشروع إنشاء حساب.
- لا يحتاج إلى مفاتيح API.
- يتم تأمين النصوص المدخلة قبل إضافتها إلى ملف SVG.
- يتم تحديد نطاقات الإعدادات الرقمية لتجنب القيم غير المناسبة.

## ⚠️ ملاحظات مهمة حول الاستضافة

يعمل GitHub Pages باعتباره خدمة استضافة ثابتة، ولذلك يتم إنشاء ملفات SVG داخل متصفح المستخدم مباشرة.

هذا الإصدار لا يوفر واجهة API على الخادم لإنشاء صور مختلفة ديناميكيا اعتمادا على معاملات الرابط.

للحصول على رابط عام ثابت للصورة، يجب تنزيل ملف SVG الناتج ورفعه إلى مستودع GitHub.

يمكن إضافة خدمة API ديناميكية مستقبلا باستخدام إحدى منصات الاستضافة المناسبة، دون أن تكون مطلوبة لتشغيل الإصدار الحالي.
