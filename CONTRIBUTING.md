# Contributing

Thank you for considering contributing to ALOSTOURA Typing SVG.

## How to contribute

1. Fork the repository.
2. Create a focused branch for your change.
3. Keep the project dependency-free unless a dependency is clearly justified.
4. Test the interface in both English and Arabic.
5. Test the generated SVG in at least one Chromium-based browser and Firefox when possible.
6. Open a pull request with a clear description and screenshots where useful.

## Code guidelines

- Use readable, modern JavaScript.
- Avoid adding a backend requirement to the static version.
- Keep user-provided text XML-escaped in SVG output.
- Preserve responsive behavior and RTL support.
- Update `CHANGELOG.md` for user-visible changes.

## Reporting bugs

Include browser/version, reproduction steps, expected behavior, and actual behavior.
