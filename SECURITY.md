# Security Policy

## Supported versions

Security fixes are applied to the latest published version.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** feature in the repository's Security tab when it is enabled. Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- A suggested fix, if available

This project runs locally in the browser and does not require user accounts, API keys, or a backend service.
