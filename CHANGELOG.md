# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-11-21

### Added
- Initial release of ALOSTOURA Typing SVG.
- Bilingual English and Arabic interface with RTL layout.
- Client-side SVG animation engine.
- Live preview and customization controls.
- SVG, Markdown, and HTML export.
- Responsive layout and GitHub Pages deployment support.
- MIT license and project contribution/security documentation.


## [1.0.1] - 2026-11-21

### Fixed
- Fixed SVG preview animation so text lines appear sequentially instead of overlapping.
- Reworked SVG clipping and timing to reveal one phrase at a time.

## [1.1.0] - 2026-11-22

### Added
- 14 selectable SVG animation effects: Typewriter, Fade, four directional Slides, Bounce, Zoom, Rotate, Blur, Glow, Flip, Elastic, and Pulse.
- 12 visual presets with coordinated typography, colors, dimensions, and effects.
- Versioned local autosave and automatic restoration of generator settings and interface language.
- Animation effect and visual template selectors in the generator.

### Improved
- Expanded SVG engine configuration validation and retained the existing client-side export workflow.
- Updated responsive styling for the new studio controls.
